# 📦 Single Product Page v1  
A modern and responsive single product page built with HTML, CSS, and JavaScript, designed to simulate a real e-commerce product detail experience with interactive image gallery and product variations.

---

## 📺 Live Demo  

🔗 [Live Demo](https://single-product-page-v1.vercel.app/)

---

## 🛠️ Features  
🖼️ Interactive image gallery with thumbnail selection  
⬅️➡️ Main image navigation arrows  
🎯 Active thumbnail highlighting  
🎨 Selectable color variations  
💾 Selectable storage options  
📱 Fully responsive layout (Desktop → Tablet → Mobile)  
🛍️ Related products grid section  
✨ Smooth hover animations and transitions  
⚡ Built with pure Vanilla JavaScript

## 🧠 How It Works  
Main product image updates dynamically when a thumbnail is clicked  
Navigation arrows cycle through product images  
JavaScript manages active states for thumbnails and variations  
Horizontal scrolling is handled using `scrollBy()`  
CSS Flexbox and Grid manage layout alignment  
Media queries adjust layout for tablet and mobile screens  
All styling handled with CSS and interactivity with Vanilla JavaScript
